# ACCP.AI Web

واجهة محادثة عربية لتجربة مساعد ACCP.AI من المتصفح. التشغيل الافتراضي تطبيق ويب بـPython، ولا يحتاج توكن Telegram أو تشغيل بوت.

## شغّله على جهازك

تحتاج Python 3.12. على Windows افتح **START_WEB.cmd**، وانتظر تثبيت المكتبات في المرة الأولى، ثم افتح:

**http://127.0.0.1:8000**

أبقِ نافذة الخادم مفتوحة أثناء الاستخدام؛ Ctrl+C يوقفه. إذا أردت التشغيل يدويًا:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -X utf8 web_app.py
```

## فعّل النموذج الذكي

من زر **تجربة محلية / إعداد الذكاء الاصطناعي** أدخل عنوان المزود، ومفتاح API، ومعرف نموذج يدعم JSON. اضغط **اختبار الاتصال وحفظ**. العنوان الافتراضي OpenRouter: `https://openrouter.ai/api/v1`. استخدم اسم النموذج المتاح في حسابك؛ لا يوجد نموذج محدد اختُبر حيًا في هذه المهمة.

المفتاح لا يُحفظ في ملفات التطبيق أو قاعدة البيانات أو تخزين المتصفح. يبقى في ذاكرة الخادم لهذه الجلسة، وينتهي بعد إعادة تشغيله أو انتهاء الاحتفاظ. بدء محادثة جديدة يحتفظ بإعداد النموذج؛ حذفه متاح من الإعدادات. طلبات النموذج تخضع لرسوم المزود. ويمكن للمسؤول ضبط `LLM_API_KEY` و`LLM_MODEL` و`LLM_BASE_URL` على الخادم بدل إدخالها في الواجهة.

بدون مفتاح يعمل **الوضع المحلي المحدود**: تستطيع اختبار الواجهة والأسئلة والتقرير، لكنه لا يمثل استدلال نموذج لغوي، ولا يعرض مؤشر شدة مكتملًا. الحالة ظاهرة في الواجهة. لا تحتاج Ollama أو GPU.

## ما الذي يمكنك تجربته؟

- اكتب الموقف بحرية، أو عدّل أحد الأمثلة الاصطناعية الثلاثة ثم أرسله.
- سؤال واحد في كل مرة، من صفر إلى ستة، مع ربط الإجابة بالسؤال الذي عُرض فعلًا.
- اطلب «وضّح السؤال» أو «لخّص ما قلته» دون احتسابهما إجابة.
- مع النموذج السحابي، شرح سياقي يستفيد من ملخص الإفادة والسؤال والإجابات السابقة.
- بعد التقرير، أضف تصحيحًا أو تفصيلًا جديدًا ليُعاد التحليل. تبقى الإفادة الأصلية محفوظة ضمن الحالة.
- افتح التقرير ونزّله HTML أو JSON أو Markdown. المسودة اختيارية بموافقة صريحة، ولا تُرسل لأي جهة.
- حدّث الصفحة أو أعد تشغيل الخادم: الحالة والسؤال محفوظان في SQLite طالما Cookie الجلسة والقرص موجودان.

## النشر والاختبارات

دليل Railway: [RAILWAY_DEPLOYMENT_AR.md](RAILWAY_DEPLOYMENT_AR.md). افتح منفذ الويب ودومين الخدمة، وأضف Volume ورمز دخول؛ لا إعداد Telegram مطلوب.

```powershell
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
```

نجح **162 اختبارًا** محليًا. راجع [TEST_RESULTS.md](TEST_RESULTS.md) و[ARCHITECTURE.md](ARCHITECTURE.md) و[KNOWN_LIMITATIONS.md](KNOWN_LIMITATIONS.md). المحرك الأصلي واختباراته محفوظان؛ ملفات Telegram القديمة موجودة للتوافق والاختبارات فقط، ولا يستوردها أو يشغّلها خادم الويب. `python-telegram-bot` ضمن اعتماديات التطوير فقط.

البيانات التجريبية تحت `data/` وتُحذف بعد 24 ساعة افتراضيًا. استخدم أمثلة اصطناعية. هذا مساعد للتوثيق والفرز الأولي، وجميع الإفادات تحتاج مراجعة بشرية؛ ليس جهة قضائية أو خدمة طوارئ.
