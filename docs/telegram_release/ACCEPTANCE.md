# حالة شروط القبول

«متحقق محليًا» يعني داخل الاختبارات المرفقة فقط، ولا يمثل ضمانًا لجميع النصوص أو التشغيل الحقيقي.

| الشرط | الحالة والدليل |
|---|---|
| الخلاف البسيط لا يُعامل تلقائيًا كتهديد | متحقق محليًا؛ مثال الجيران ينتهي بصفر أسئلة |
| عدم قلب النفي الصريح إلى إثبات | متحقق في مصفوفة النفي وحالات النطاق؛ التعميم اللغوي غير مثبت |
| أسئلة تكيفية ومنع تكرارها وإنهاء مبكر | متحقق محليًا مع حفظ السؤال، واستثناء سلامة مبرر عند تطور جديد |
| منع الوقائع بلا مصدر وفصل النشر عن التهديد | متحقق للمخطط والاقتباس والمصدر وحالات الاختبار؛ صحة كل معنى عربي غير مثبتة |
| عدم تضخيم الشدة بالأحداث المتكررة | متحقق في حالات التأكيد والمهلة والنسخة المرسلة |
| إعادة فحص السلامة مع معلومة جديدة | متحقق محليًا قبل انتظار الاستدلال |
| مسار إرشادي للخلاف المحسوم | متحقق مع محاكاة مستخرج ناجح؛ فشل النموذج يعلن الحاجة للمراجعة |
| تقرير عربي واضح مع مصادر وحدود وموافقة | منفذ ومختبر آليًا، مع أمثلة HTML وJSON وMarkdown |
| Telegram كتدفق محادثة كامل | متحقق بمهايئ المكتبة مع Bot/HTTP محاكيين؛ الاتصال الحي غير مختبر |
| فصل الجلسات واسترجاعها بعد إعادة التشغيل | متحقق محليًا على SQLite؛ إعادة نشر Railway والقرص الحي غير مختبرين |
| Hosted LLM دون GPU محلي | منفذ ومختبر بمحاكاة HTTP؛ جودة نموذج حي غير مقاسة |
| عدم تضمين أسرار حقيقية | لا توجد مفاتيح تشغيل في الحزمة؛ .env.example فارغ وأمثلة الاختبار مصطنعة |
| Docker وRailway | ملفات جاهزة ومراجعة بنيويًا؛ بناء الحاوية ونشرها **غير متحققين** لغياب Docker وحسابات الخدمة |
| نجاح الاختبارات القديمة والجديدة | السجل الفعلي والعدد في TEST_RESULTS.md |
| دقة واقعية واعتماد إنتاجي | **غير متحقق**؛ بيانات اصطناعية محدودة وأخطاء لغوية معروفة |

لم تُعلّم البنود غير المختبرة على أنها ناجحة. الحزمة تسليم تنفيذي للعرض التجريبي مع حدود معلنة؛ لا تمثل إعلان استيفاء اعتماد إنتاجي أو سلامة عامة.
