# ACCP.AI — نسخة العرض المطوّرة

نظام مقابلة عربي تجريبي لتوثيق الإفادات وفرزها الأولي. مبني على المشروع المرفق نفسه، مع فصل مسؤولياته وإضافة اختبارات وحفظ دائم للجلسات. **ليس نظامًا قضائيًا أو نظام سلامة معتمدًا.**

## التشغيل الذي تحتاجه للعرض

`Telegram → تطبيق Python على Railway → Hosted LLM API → التحليل والتقرير → Telegram`

1. أنشئ بوتًا من BotFather واحفظ التوكن في Railway فقط.
2. ارفع **محتويات هذا المجلد** إلى جذر مستودع GitHub خاص.
3. اربط المستودع بخدمة Railway، وأضف Volume على `/data`.
4. أضف المتغيرات الموضحة في `.env.example`، ثم انشر نسخة واحدة فقط.
5. افتح البوت واكتب `/start`.

التفاصيل: [دليل Railway](RAILWAY_DEPLOYMENT_AR.md) و[دليل Telegram](TELEGRAM_SETUP_AR.md). لا تحتاج تشغيل Ollama أو GPU على اللابتوب.

## ما توفره النسخة

- من صفر إلى ستة أسئلة حسب المعلومات الناقصة، مع حفظ السؤال الفعلي ومعرّفه.
- فصل الإثبات بالإفادة والنفي وعدم اليقين والتعارض، وربط الاقتباسات بإزاحات النص ومصدرها.
- قواعد عربية سياقية للنفي والشرط والحدود بين الجمل، مع استخراج LLM منظم والتحقق بـPydantic.
- تصنيف متعدد عند وجود سند، وفصل المقترحات الآلية عن التصنيفات المقبولة.
- خمسة مخرجات مستقلة: الشدة، السلامة الحالية، الاستعجال الرقمي، أولوية المراجعة، والمسار.
- تقارير عربية JSON وMarkdown وHTML باتجاه RTL. يمكن طباعة HTML من المتصفح؛ لا يوجد مولد PDF في البوت.
- مسودة اختيارية لا تُنشأ إلا بعد موافقة صريحة، ولا تُرسل لأي جهة رسمية.
- SQLite على Volume، وأقفال لكل مستخدم، وحفظ الرد قبل الإرسال، ومنع أثر التحديث المكرر.
- قائمة سماح مغلقة افتراضيًا، وحذف بيانات الجلسات، ومعالجة أخطاء بلا تسجيل نصوص الشكاوى أو المفاتيح.

## تجربة محلية بلا أي مفتاح

تحتاج Python 3.12. من داخل مجلد المشروع:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -X utf8 main.py --provider offline
```

هذه تجربة القواعد المحلية فقط؛ يوضح التقرير أن النموذج لم يُستدعَ وأن درجة الشدة غير مكتملة. لا تشغّل Telegram محليًا بنفس التوكن أثناء تشغيله على Railway.

## إعادة الاختبارات

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe evaluation/independent_evaluation.py
```

النتائج المقاسة وحدودها في [TEST_RESULTS.md](TEST_RESULTS.md)، وتصميم النظام في [ARCHITECTURE.md](ARCHITECTURE.md)، والتغييرات في [DEVELOPMENT_REPORT_AR.md](DEVELOPMENT_REPORT_AR.md).

راجع [KNOWN_LIMITATIONS.md](KNOWN_LIMITATIONS.md) قبل العرض: لم يُختبر اتصال حي بـTelegram أو Railway أو LLM في بيئة التطوير، ولا يوجد ضمان لفهم جميع الصيغ العربية. ملفات `examples/` حالات اصطناعية فقط.
