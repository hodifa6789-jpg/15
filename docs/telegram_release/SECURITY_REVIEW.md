# مراجعة أمنية محلية وحدودها

هذه مراجعة كود واختبارات تعاقدية محلية، وليست اختبار اختراق أو اعتمادًا أمنيًا أو فحص CVE حيًا.

| السطح | المعالجة | الدليل المحلي |
|---|---|---|
| الوصول | محادثة خاصة وقائمة سماح فارغة افتراضيًا؛ /id فقط لغير المصرح | اختبارات المهايئ للحساب غير المصرح والمجموعات |
| تداخل الجلسات | user_id من Telegram، أقفال مستقلة، لا اختيار مسار تقرير من نص المستخدم | اختبار مستخدمين وتقرير الحساب الآخر |
| التكرار والتزامن | update_id دائم، revision CAS، رد محفوظ، سؤال محفوظ بمعرفه | restart/duplicate/concurrent/stale-write tests |
| إفادات غير موثوقة | Schema صارم، اقتباس ومصدر ومعنى محلي، لا تنفيذ أو أدوات من مخرجات LLM | prompt injection، مصدر خاطئ، Enum غير صالح |
| عرض التقارير | HTML escaping وCSP دون scripts، Markdown escaping، filename validation | HTML injection واختبار عنوان Markdown داخل الإفادة |
| المسودات | موافقة صريحة مرتبطة بالقضية؛ فحص ثانٍ في renderer | رفض دون موافقة، زر موافقة لقضية قديمة |
| الأسرار والأخطاء | متغيرات بيئية، رسائل أخطاء عامة، لا تسجيل نصوص أو أجسام أخطاء المزود | محاكاة خطأ بمحتوى حساس والتحقق من عدم حفظه |
| التخزين | WAL ومعاملات وصلاحيات Linux 700/600 وTTL وsecure_delete | إعادة فتح DB، الحذف، انتهاء الاحتفاظ |
| الموارد | حد 3000 حرف للإفادة و1500 للإجابة، توازٍ محدود ومحاولات محدودة | طول الرسالة، timeouts، 429/5xx مقابل 401 |
| الحاوية | root لتهيئة /data فقط ثم UID/GID10001، رفض symlink لمسارات البيانات المحددة | مراجعة كود؛ لم يجر تشغيل Docker |

البيانات غير مشفرة على مستوى التطبيق. احتفاظ Telegram ومزود LLM ونسخ Volume الاحتياطية خارج إدارة التطبيق. لا يوجد معدل طلبات موزع أو عزل متعدد المستأجرين أو حماية DDoS؛ قائمة السماح وعدد المستخدمين المحدود جزء من نطاق العرض. `LLM_BASE_URL` إعداد مسؤول موثوق وليس مدخل مستخدم.

يمكن أن تفوت قواعد الاستبعاد محاولات لغوية ملتوية، ويمكن أن تفوت أحداثًا حقيقية. لا تتعامل مع نجاح اختبارات prompt injection كضمان حصانة. لا تُدخل بيانات أشخاص حقيقية في العرض.

السجلات تحتوي فقط نوع خطأ أو مؤشرات تشغيل عامة في مسارات التطبيق المراجعة. راجع أيضًا إعدادات السجل والاحتفاظ لدى المزود والمنصة قبل النشر. الحزمة النهائية تستبعد قواعد بيانات التشغيل وملفات .env وبيئات Python، وتحتوي .env.example بقيم أسرار فارغة وأمثلة اصطناعية معلّمة.
