# تقرير التطوير — ACCP.AI

تاريخ التسليم: 24 أكتوبر 2026. طُوّر المشروع المرفق؛ لم يُستبدل بمنتج آخر. سجل التدقيق الأولي في [AUDIT.md](AUDIT.md)، والمقارنة التفصيلية للملفات في `quality/change-manifest.json`.

## المشكلة والنتيجة

كانت خطة الأسئلة تستخدم إشارات كلمات منفصلة عن Grounding، وتعيد حساب السؤال عند ورود الإجابة. وكانت الجلسة محفوظة في ذاكرة Telegram فقط. لذلك كان ممكنًا أن تؤثر كلمة منفية على المسار، أو تضيع الحالة بعد إعادة التشغيل، أو ترتبط إجابة بسؤال آخر. نجاح اختبارات النسخة الأصلية لم يغَط هذه الفجوات.

أصبح المصدر الموحد للقرار `FactState`. يجمع الإفادات الموثقة، يحتفظ بالنفي والشك والتعارض، ويغذي التصنيف والتخطيط والشدة والتقرير. تُحفظ هوية السؤال ونصه قبل إرساله، وتُربط الإجابة به بعد الاسترجاع. الخلاف المحسوم ذو الهدف الواضح ينتهي دون أسئلة إضافية في الاختبار المحاكى.

## الفهم والاستخراج

أضيفت نماذج Pydantic صريحة وأنواع مسموحة، ومصدر وإزاحات واقتباس حرفي وحالة تحقق مستقلة لكل إفادة. تُعالج حدود الجمل والعبارات الاعتراضية وأدوات النفي القريبة والشرط والمستقبل والشك. النفي المزدوج يتحول إلى عدم يقين بدل إثبات تلقائي. تُرفض تعليمات تغيير التصنيف داخل الإفادة، والمقترحات التي لا يدعمها المصدر والمعنى المحلي.

هذا تحسن هندسي قابل للاختبار، لكنه لا يحقق فهمًا عربيًا عامًا. التحقق الدلالي المحلي ما زال قائمًا على قواعد محدودة، وقد يرفض صياغة صحيحة اقترحها النموذج. ظهرت ثلاث حالات تصنيف فائتة في المجموعة المحجوزة النهائية، ووُثقت دون تعديل القواعد عليها بعد القياس. لا يوجد تدريب أو ضبط على بيانات ميدانية.

## محرك المقابلة

يفصل `interview_planner.py` إنشاء المرشحين وتغطية المعلومات واختيار السؤال وقرار التوقف عن الصياغات. تُحسب منفعة تقريبية من تأثير المعلومة وعدم اليقين وعبء السؤال؛ الأوزان هندسية وليست تقديرًا احتماليًا متعلمًا للقيمة المعلوماتية. تُستبعد الوقائع المحسومة والأسئلة المجابة ولو كانت الإجابة «لا أعرف». يُسمح باستفسار تعارض أو إعادة تحقق من السلامة عند تغير جوهري، مع سقف ست إجابات.

## الزمن والشدة والتقرير

حُفظت مصادر الإفادات وتطور المهلة وإرسال النسخة والتأكيد على الرسالة نفسها. تُدمج التأكيدات المتكررة، ولا تُضاعف أوزان الإصابة أو الخوف أو الأحداث المترابطة. درجة الشدة منفصلة عن السلامة الحالية والاستعجال الرقمي وأولوية المراجعة والمسار. لا تسقط أولوية التهديد الجسيم لمجرد عدم حصول أذى، ولا تُعرض درجة مكتملة بعد فشل النموذج أو وجود تعارض غير محسوم.

التقرير عربي حتمي الصياغة، ويقتبس السياق الداعم دون توليد أشخاص أو وقائع جديدة. يتضمن الأصل والنفي والشك والمصادر والزمن والأدلة غير المفحوصة والإرشادات. أضيف HTML عربي RTL قابل للطباعة بدل عرض Markdown خام. المسودة مشروطة بموافقة صريحة في التدفق وفي دالة الإنشاء نفسها، ولا توجد وظيفة إرسال لجهة رسمية.

## Telegram والتخزين

أضيف SQLite بـWAL ومعاملات تضم الجلسة والرد المنتظر ومعرف التحديث، مع مراجعة رقم النسخة وأقفال لكل مستخدم. تعالج الطلبات لمستخدمين مختلفين بالتوازي المحدود. تُرفض الإجابة السريعة الثانية إذا لم تكن مرتبطة بالمراجعة التي عرضت السؤال. التكرار لا يكرر أثر التحليل؛ إرسال الشبكة نفسه يظل قابلًا للتكرار عند انهيار بين الإرسال وتسجيل تأكيده.

تدعم الواجهة الأوامر الثمانية والأزرار، وتعمل في المحادثة الخاصة وقائمة السماح فقط. `/id` متاح لمعرفة المعرف دون صلاحية مقابلة. التقارير تُنشأ في الذاكرة وتُرسل لصاحب الجلسة. الحذف يمحو المحتوى المحلي ويحفظ علامة منع إعادة تنفيذ التحديث حتى انتهاء الاحتفاظ. العمر الافتراضي 24 ساعة؛ هذا لا يمحو نسخ الخدمات الخارجية.

## الاستدلال والنشر

بوابة HTTPS متوافقة مع OpenAI Chat Completions، مع JSON Schema وتحويل محدود إلى JSON Object عند عدم دعم الصيغة صراحة. إعادة المحاولة محدودة بالأخطاء المؤقتة؛ لا تُسجل المفاتيح أو نصوص الإفادات. اسم النموذج والمزود متغيران. CLI يستخدم التدفق نفسه، وOllama خيار قديم منفصل لا يحتاجه نشر Railway.

أضيفت تهيئة Docker/Python 3.12، وSQLite على Volume `/data`، وقفل عملية Long Polling واحدة، وخفض الصلاحيات بعد إعداد ملكية القرص. لا يحتاج PostgreSQL أو GPU لعرض صغير بعملية واحدة. توجد مهمة GitHub Actions للاختبارات والبناء، لكنها لم تُنفذ على GitHub في هذه المهمة.

## الملفات والتوافق

أعيد تنظيم `engine.py` كواجهة متوافقة، وطُوّرت ملفات nlp وgrounding وtimeline وbot_flow وtelegram_bot وstorage وcloud_llm وmain وrepair_existing. أضيفت وحدات domain وarabic_semantics وfact_state وinterview_planner وrisk وreporting وpersistence وservice وconfig وworker_lock وإدارة الحذف. بقيت ملفات الاختبارات الأصلية دون تغيير. تغير شكل الحالة والتقرير إلى schema_version 2 مع الاحتفاظ بحقول التوافق اللازمة للاختبارات وإعادة البناء.
