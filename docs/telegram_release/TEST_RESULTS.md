## التقارير وتجربة المثال

وُلّد مثالان عبر تدفق محاكى دون أي طلب خارجي: خلاف الجيران انتهى بصفر أسئلة ومسار assisted_resolution؛ والابتزاز مع تطور لاحق انتهى بخمسة أسئلة ومسار priority_human_review. ملفات JSON تميز المحاكاة صراحة. أُجري فحص HTML في Chrome headless بعرض 1180 و390 بكسل: RTL، 15 قسمًا، بلا scripts أو تمرير أفقي. فُحصت لقطات سطح المكتب والهاتف بصريًا. السجل `quality/report-render-check.json`.

## ما لم يُختبر

| المجال | الحالة |
|---|---|
| استدلال Hosted LLM حقيقي | غير منفذ؛ لا API key/model متاحين |
| Telegram حي | غير منفذ؛ لا توكن تشغيل متاح |
| نشر Railway وRestart على Volume حي | غير منفذ؛ لا خدمة متاحة في المهمة |
| Docker build/run | غير منفذ؛ Docker غير موجود في البيئة |
| GitHub Actions | ملف CI أضيف، ولم تُشغّل المهمة على GitHub |
| ضغط واسع / اختراق / CVE | غير منفذ |

لا تُعد المحاكاة أو الأرقام الاصطناعية دليل سلامة أو دقة واقعية. يحتاج القبول النهائي للعرض تحقق الخدمات المذكور في RAILWAY_DEPLOYMENT_AR.md، ويحتاج الاستخدام الحقيقي مراجعة مستقلة أوسع.

## إعادة التنفيذ

```powershell
python -m pip install -r requirements.txt
python -m pip check
python -m unittest discover -s tests -v
python evaluation/independent_evaluation.py --output quality/recheck.json
python evaluation/generate_examples.py
```

لتقييم نموذج حي بعد ضبط LLM_API_KEY وLLM_MODEL وLLM_BASE_URL: `python evaluation/independent_evaluation.py --live --output quality/live-results.json`. يُجري طلبات مدفوعة بحسب المزود على حالات اصطناعية. يخرج برمز 2 إذا فشل أي طلب؛ مقاييس المحادثات في هذا الأمر تبقى محلية ومعلّمة بذلك.
